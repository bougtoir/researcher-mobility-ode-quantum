# 査読者視点の批判的レビュー（安全保障・国家技術戦略論文向け）

対象プロジェクト: `researcher_mobility_ode`（OpenAlex ベースの研究者流動連立 ODE モデル）  
レビュー目的: 安全保障領域での論文化・政策提言に先立ち、査読者が指摘しうる構造的・方法的問題を整理し、修正案を提示する。

---

## 1. レビューの前提

- データ源: OpenAlex API (`subfields/1702` AI/ML, `subfields/3107` Atomic and Molecular Physics を試行)。
- モデル: 文明圏（US / 英語圏 ex-US / 欧州大陸 / 日本 / 中国圏 / インド圏 / イスラム圏 / その他文明圏）ごとに 6 コンパートメントの ODE。
- 新規流入: `I = I0 + r·P_D`（飽和型は `I0 + r·P_D / (1 + ε·P_D)`）。
- 閾値: `M = k × c_bar`（国内でその研究分野を維持するのに必要な最小共著者プール）。
- 拡張: 飽和流入、ブートストラップ CI、`k` 感応度、時間変化パラメタ、国別解像度、行動層、ネットワーク外部性、政策反実仮想。

## 2. 指摘事項（優先度順）

### 2.1 最優先 — 投稿前に必須修正

#### 1. 因果解釈と「政策介入」の言い換えリスク
- **内容**: OpenAlex の観察データから推定した遷移率を構造パラメータとして反実仮想シミュレーションに使っているが、海外流出・帰国・PI 到達は研究者個人の選択と制度環境の同時均衡。各遷移率を独立に操作しても、他のコンパートメントが同時に変化するため「β を 30% 上げれば T が増える」は機械的なシナリオであって因果効果ではない。
- **致命度**: 高（desk reject または major revision: "endogeneity" / "policy relevance"）
- **修正効果**: 高（主張の強さを正当な範囲に押さえ、採択可能性を上げる）
- **実行可能性**: 中（新規データ不要、記述とフレーミングの変更）
- **修正案**:
  - タイトル・Abstract・Conclusion で「政策効果（impact）」ではなく「反実仮想シナリオ（counterfactual scenario）」と明示。
  - Methods に「遷移率は condition on observed career histories の条件付き確率であり、介入の因果効果を識別するものではない」と記載。
  - `policy_counterfactuals.py` の出力キャプションを「mechanical counterfactual, not a causal estimate」と統一。

#### 2. コホート・遷移率の定義が暗黙的
- **内容**: `career_start` は初発表年、`abroad` は `career_start + ABROAD_WINDOW` 内のいずれかの所属国が origin 所属と異なること、`recent_group` は「最後に観測された 3 年間の最頻出身国」等、多数の判断がコードに埋め込まれている。学術誌の査読者はこれらを「ad hoc」と見る。
- **致命度**: 高（Methods の信頼性）
- **修正効果**: 高
- **実行可能性**: 高（既存コードの記述化）
- **修正案**:
  - `cohort_extraction.py` の各判断（career_start, abroad window, PI 判定, hit 判定）を flowchart / 表として Methods に掲載。
  - 感応度分析として `ABROAD_WINDOW` と「PI 判定 = last author on a hit work」の代替定義を実装し、Appendix へ。

#### 3. 小規模グループの不安定な推定
- **内容**: `Other Civilizations`、`Other Western`、量子分野の `Japanese` / `Hindu` 等はサンプルが少なく、遷移率のブートストラップ CI が広い。現状の `intervention_summary.md` には点推定のみが並び、不確実性が目に見えない。
- **致命度**: 高（過信頼主張）
- **修正効果**: 高
- **実行可能性**: 高（`bootstrap_ci.py` 済）
- **修正案**:
  - 全主張に 95% CI を付与。図表は点のみではなく error bar/帯で示す。
  - サンプルサイズ `n` を各文明圏・各遷移ごとに必ず記載。
  - サンプルが `n < 30` 程度のグループは ODE 解析から除外し、Appendix の「低統計力グループ」表にまとめる。

#### 4. 閾値 `M = k × c_bar` の経験的根拠が薄弱
- **内容**: コンセプトは魅力的だが、「最小存続共著者プール」がなぜ「平均著者数 × 年間独立 last-author 群数」で測定できるのか、理論・実証的根拠が不十分。分野間交流、国際共著、学生・技術者、研究資金・設備等が無視されている。
- **致命度**: 高（モデルの妥当性）
- **修正効果**: 高
- **実行可能性**: 中（`k_sensitivity.py` は実装済みだが、根拠付けは追加調査が必要）
- **修正案**:
  - `M` を「仮想的な最低限の議論コミュニティ規模の一つの指標」として位置づけ、複数の `k`（観測値、過去最低値、分野の会議審査体制に基づく外部知見）で感応度を示す。
  - `k_sensitivity.py` の結果を本文 Fig/Table 化。
  - 別分野（量子、半導体）で `k` と `c_bar` がどう変わるか比較し、指標の分野横断妥当性を議論。

#### 5. 文明圏間の相互作用が欠落
- **内容**: 現状の ODE は各文明圏が独立した 6 次元系。流出先 `A` は「自文明圏出身者が abroad にいる数」であり、他文明圏の在庫や流入圧から影響を受けない。人材獲得競争はゼロサムであるにもかかわらず、各グループの流入 `I` は独立に決まる。
- **致命度**: 高（安全保障文脈では「突出」が問題視されるが、モデルは競争を内生していない）
- **修正効果**: 高
- **実行可能性**: 中（`network_externalities.py` を拡張）
- **修正案**:
  - 少なくとも `I0` に他文明圏の `P_A` または `T` で重み付けした外部圧項を追加（例: `I0_i · f(P_A_others / T_others)`）。
  - 全球での研究者総数制約を加え、一国/一文明圏の inflow 増が他の outflow 増と同時に決まる closed system を作成。
  - 文中で「このモデルは競争均衡ではなく、あくまで各国の国内コミュニティ維持能力の横断面比較である」と限定。

### 2.2 高優先 — 大きく改善させるべき

#### 6. `r` と `I0` の識別と `safety_factor` の恣意的選択
- **内容**: `r_obs = I / P_D` は線形 ODE を爆発させるため、`safety_factor=0.5` で `r_crit` に縛る。これは数理的に透明だが、`safety_factor` の値は著者の選好で決まり、結果に強い影響を与える。政策シミュレーションで「PI 駆動の新規流入」を操作する際、その上限の根拠が不明確。
- **致命度**: 中〜高
- **修正効果**: 高
- **実行可能性**: 中（感応度分析追加）
- **修正案**:
  - `safety_factor` を {0.25, 0.5, 0.75, 0.9} で感応度分析し、Fig/Table 化。
  - 飽和型関数での `epsilon` 決定（`K = max(P_D_obs, 5·P_D_obs)`）も感応度化。
  - 外部データ（PhD 修了数、研究費配分）で `I0` を照合し、感応度と合わせて robustness を主張。

#### 7. 平衡解析の時間的外挿
- **内容**: パラメタは 2000–2016 年の観測から推定され、それを長期均衡に外挿。AI/ML・量子分野は 2010 年以降に構造変化が大きい。`time_varying.py` はあるが、後期コホートが小さく、統計力に乏しい。
- **致命度**: 中
- **修正効果**: 高
- **実行可能性**: 中（より大きな OpenAlex サンプル取得が必要）
- **修正案**:
  - 2010 年カットの他に、2015 年カットでも実行し、定性結果が反転しないか確認。
  - 時系列プロットで `T_eq`、`M`、`margin` を年度別に追う。ただしこれには「rolling window」で連続 ODE を推定する拡張が必要。

#### 8. 海外所属の測定誤差
- **内容**: OpenAlex の `country_code` は機関の所在国。研究者の国籍、滞在先、二重所属、リモート勤務、短期訪問を区別できない。安全保障文脈では国籍・クリアランスが重要だが、モデルでは所属機構国しか見えない。
- **致命度**: 中
- **修正効果**: 中
- **実行可能性**: 中（手動国名標準化は困難；ORCID/人工審査の追加データが ideal）
- **修正案**:
  - Methods の Limitations で「国籍ではなく機関所在国」であることを明記。
  - 可能であれば ORCID プロファイルの所在地変遷と突き合わせるサブサンプル検証。

#### 9. 量子分野のサンプル不足
- **内容**: `subfields/3107` では US・欧州・中国圏のみが安定し、日本・インド等が除外された。安全保障関連分野（量子）で「日本が脆弱か」は問えない。これは `max-authors=2000` の試行サンプルが小さいことに起因。
- **致命度**: 中〜高（量子は安全保障論文の主要ケース）
- **修正効果**: 高
- **実行可能性**: 中（大規模再取得、OpenAlex 有償 tier 検討）
- **修正案**:
  - 量子分野について `max-authors` を 5000–10000 に増やし再抽出。
  - 日本・インドを個別に検証できない場合は「この分野では日本の統計力不足のため推定不能」と断る。

#### 10. 政策反実仮想の現実的制約が欠如
- **内容**: `policy_counterfactuals.py` は係数に単純な乗数をかける。予算、制度の限界、異文明圏間の反応、研究テーマの質的変化を無視している。
- **致命度**: 中
- **修正効果**: 中
- **実行可能性**: 高（主記述の変更）
- **修正案**:
  - 結果を「制度変更の機械的な下界・上界」と説明。
  - 政策レバーに対応する遷移率の選択理由を明確化（例: 帰国率 β は帰国研究者支援、PI 率 p_D は研究費の若手 PI 枠）。

### 2.3 中優先 — 補強するとより説得力が増す

#### 11. 未観測異質性
- 研究テーマ、機関ランク、学位取得国、性別、ビザ制度等が無視されている。可能な限り共変量を追加し、層別 ODE を実施。

#### 12. 外部流入の開放性
- `I0` は自文明圏出身者の国内流入を含む。国際学生・ポスドク受入や移民研究者の流入を別コンパートメントに分離した方が、安全保障文脈では現実的。

#### 13. データの再現性とスナップショット固定
- OpenAlex は更新される。論文投稿時のスナップショット日・バージョンを明示し、`openalex_client.py` の cache チェックサムを記録。

#### 14. 図表・用語の一貫性
- `point of no return`、`safety_factor`、文明圏名は学界標準語ではない。初出で定義。日本語版と英語版で図表テキストの完全な言語一貫性を保つ（別々の `figures_ja.py` / `figures_en.py` を推奨）。

#### 15. 安全保障文脈との接続
- 論文が政策者に訴えるなら、「どの遷移に介入するか」だけでなく「どの技術分野が最も供給鏡脆弱性を持つか」「どの文明圏が過度に依存しているか」を示す表が必要。

## 3. 総合判断

### 強み
1. **コンセプトの新規性**: 人材の純増・純減ではなく「遷移係数」に介入する視点は説得力があり、安全保障分野の人材戦略論に寄与する。
2. **透明性**: Python スクリプト、OpenAlex 実データ、環境変数ベースの再現性設計により第三者検証が可能。
3. **拡張性**: 飽和流入、ブートストラップ CI、感応度、時間変化、国別解像度などを実装しており、方法論の成熟度が高い。

### 現在の主要リスク
- **因果と構造の混同**: 反実仮想を政策効果と言い換えると、査読者から "overclaim" で reject される。
- **データの小規模グループ**: 一部文明圏で `n` が小さく、均衡値の信頼性が低い。
- **閾値 `M` の根拠**: 興味深い指標だが、学術的に説得力を持たせるにはさらなる理論・実証的裏付けが必要。
- **文明圏間競争の不在**: 安全保障論文の核心「突出防止・寡占回避」には、群間の競争と feedback が欠けている。

### 投稿前にすべきこと（推奨順）
1. 因果・反実仮想のフレーミングを徹底修正。
2. 全主張にブートストラップ CI とサンプルサイズを付与。
3. `M = k × c_bar` の感応度と根拠を明文化。
4. `network_externalities.py` または `policy_counterfactuals.py` に、文明圏間の競争/供給制約を追加。
5. `safety_factor` と `epsilon` の感応度を追加。
6. 量子分野の大規模再抽出（`max-authors` 増）と日本/インドの安定推定。
7. 投稿前に公開リポからのクリーン再現性検証を実施（`note-036cd969020c45479de82c6d49c0264c`）。

## 4. ユーザーの価値観との対応

> 「どこかが突出して移行係数ハックしてこないように安全域の範囲で早期介入して、各々の文明圏が均衡するような未来を想像している。文明圏の多様性は大切。進化の袋小路にならないよう寡占体制をふせぎたい」

この価値観を反映するには、現状の「各国の domestic active pool を維持するための必要係数変化率」を示す PNR 指標だけでは不十分。以下の追加が必要：

- **全球制約の導入**: 全文明圏の研究者総数を一定とする closed system を作り、一国の inflow 増が他国の outflow 増として現れるようにする。
- **多様性指標**: 各文明圏の `T_i / 総計 T` の集中度（Herfindahl 指数）を定義し、シミュレーションで寡占化が進むか追跡。
- **安全域の可視化**: `r` や `β` の多値操作で、どの文明圏が `T_i < M_i` に陥るかの「安全域」を phase diagram で示す。
- **協調シナリオ**: 各国が独自に inflow を上げる「競争シナリオ」と、国際的な talent circulation を保つ「協調シナリオ」を対比。

これらを追加すれば、「寡占を防ぎながらの早期介入」という主張が数値的に示せる。
